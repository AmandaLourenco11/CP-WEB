# GourmetOn 

Landing page de um aplicativo fictício de delivery de comida, desenvolvida como projeto para a disciplina de Desenvolvimento Web.

## Descrição da aplicação

O **GourmetOn** é um site institucional (landing page) criado para apresentar um app de delivery de comida. A página foi desenvolvida em **React** com **Tailwind CSS**, seguindo uma abordagem de componentização, onde cada seção do site é um componente independente.

A aplicação é composta pelas seguintes seções:

- **Header**: menu de navegação fixo no topo, com links para as seções da página e versão responsiva para dispositivos móveis.
- **Hero**: seção de destaque inicial com chamada principal, imagem de prato e botão de call-to-action.
- **Sobre**: apresenta os principais benefícios de usar o GourmetOn (entrega rápida, variedade de restaurantes e pagamento fácil).
- **Funcionalidades**: lista os recursos do app (busca por tipo de comida, filtros inteligentes, rastreio ao vivo e pagamento integrado), com ícones ilustrativos.
- **Menu**: exibe pratos em destaque consumindo dados em tempo real da API pública [TheMealDB](https://www.themealdb.com/api.php).
- **Avaliações**: depoimentos de clientes fictícios sobre a experiência com o app.
- **Formulário**: formulário de cadastro de e-mail para receber novidades e cupons, com feedback visual de envio.
- **Footer**: informações de contato, redes sociais e direitos autorais.

## Tecnologias usadas

- **[React](https://react.dev/)**: biblioteca para construção da interface e componentização
- **[Vite](https://vitejs.dev/)**: ferramenta de build e servidor de desenvolvimento
- **[Tailwind CSS](https://tailwindcss.com/)**: estilização utilitária dos componentes
- **[Lucide React](https://lucide.dev/)**: biblioteca de ícones
- **[TheMealDB API](https://www.themealdb.com/api.php)**: API pública utilizada para buscar os pratos exibidos na seção "Menu"
- **JavaScript (JSX)**: linguagem principal da aplicação
- **HTML5 / CSS3**
